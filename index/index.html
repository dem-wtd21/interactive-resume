Проекты и лабораторные работы

Веб-приложение «Дневник ментального здоровья»

Разработка многоуровневой информационной системы для психологического самомониторинга. Включает сессионную регистрацию, интерактивный интерфейс фиксации эмоций, switch-алгоритм генерации советов и встроенный опросник депрессии PHQ-9 с автоматическим подсчетом баллов.
Стек технологий:
PHP (PDO) MySQL / MariaDB XAMPP HTML5 / CSS3
Интерактивы и отчетные материалы:
🔗 Исходный код скриптов 📊 Физическая схема БД (Дизайнер) 📐 UML-диаграмма классов 📄 PDF-отчет по курсовой

Десктопное приложение «Математическая игра»

Создание интерактивной кроссплатформенной игры с графическим интерфейсом на базе ООП-парадигмы. Реализованы алгоритмы случайной генерации арифметических задач с адаптивной сложностью, проверка ответов, динамический таймер (javax.swing.Timer) и система сохранения рекордов.
Стек технологий:
Java Core Java Swing (GUI) JVM Random API
Интерактивы и отчетные материалы:
